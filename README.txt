## Importante
PWA não funciona corretamente abrindo o index.html via file://.
É necessário publicar via HTTPS (por exemplo, GitHub Pages, Netlify ou Vercel)
ou testar em localhost.

Depois de publicado:
- Android/Chrome: use "Instalar app" ou "Adicionar à tela inicial".
- iPhone/Safari: Compartilhar -> Adicionar à Tela de Início.
